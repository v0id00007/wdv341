# wdv341
#Version Control Software - A system that tracks file changes over time, enabling collaboration and history management.


#add - Stages changes in the working directory, preparing them for the next commit.


#commit - Creates a permanent snapshot of staged changes in the local repository.


#push - Uploads local commits to a remote repository.


#pull - Fetches and merges remote changes into the local branch.


#clone - Creates a local copy of a remote repository, including its full history.
